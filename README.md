# LeadzIn Reseller Landing Page

A fully responsive, mobile-first promotional website built for an authorized LeadzIn partner.
Designed for smartphone users with smooth animations, gold & black branding, and a clean UX flow.

## Features

- Reseller profile section (name, contact, partner code)
- What is LeadzIn — company overview & founder quote
- 7 Income Streams explained with contact prompts
- All 4 packages (Supreme, Premium, Ultimate, Classic) with buy links
- Exclusive coupon codes section with tap-to-copy functionality
- Before & after pricing with savings highlighted
- Sponsored international trips showcase
- Why LeadzIn — key reasons to join
- Sticky nav with scroll progress bar
- Floating call button
- Contact section with phone, Instagram & Facebook links
- Smooth scroll animations with Intersection Observer
- Animated stat counters

## Tech Stack

- Pure HTML, CSS, JavaScript (no frameworks)
- Google Fonts — Bebas Neue + Outfit
- CSS custom properties for theming
- IntersectionObserver API for scroll animations
